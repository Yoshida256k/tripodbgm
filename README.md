# トライポッド サウンド設定

高専祭の展示「トライポッド爆音光化」で、場面ごとに鳴らす音（電子音・MP3・WAV）を差し替える GUI です。
マイコン（YD-RP2040）と USB でつないで使います。

**開く：https://yoshida256k.github.io/tripodbgm/**

## 使い方
1. マイコンを USB でつなぎ、上の URL を開いて「接続」を押す。
   - PC：Chrome / Edge（Web Serial）
   - Android：Chrome（WebUSB）
2. 「場面」タブで、場面ごとに鳴らす音の候補を選び、「マイコンに保存」を押す。
   - 候補が2つ以上あると、鳴るたびにランダムに選ぶ。
   - 「BGMの流し方」で、プレイ中も待機BGMを流すかどうかを選べる。
3. 「音源」タブで、音のファイルをマイコンに転送する。
   - 30秒以下のファイルは WAV に変換して送る。どの場面でも使える。
   - それより長い MP3 はそのまま送る。BGM の場面だけで使える。

ブラウザの「インストール」でアプリとして入れておくと、インターネットがない場所でも開けます。

## リポジトリの中身
| 場所 | 内容 |
|---|---|
| `web/` | この GUI（GitHub Pages で公開） |
| `src/game/` | マイコンの本番用プログラム（PLC の信号で場面を判定し、音・光・LCD を出す） |
| `src/test/` | 回路の動作確認用プログラム |
| `platformio.ini` | PlatformIO の設定（環境 `game` / `test`） |
| `GUI起動.bat` | PC で GUI をアプリの窓として開く |
| `トライポッド爆音光化_仕様書vscode.md` | ハード・ソフトの仕様書 |
| `トライポッド既存構成_分析レポート.md` | 既存のトライポッド機（PLC・ラダー）の分析 |
| `遊び方/` | 来場者向けの遊び方シート（A4 縦 1 枚）。印刷は `遊び方_A4.pdf`、元は `遊び方_A4.html` |

音源（MP3 など）は著作権があるので入れていません。そのため `test` のメニュー5（MP3 再生）は、`data/test.mp3` に手元の MP3 を置かないとビルドできません。
